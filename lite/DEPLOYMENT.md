# Liteの配布とモバイル受入

## 現行方針（本人承認：2026-09-16）

既定の配布先は、既存の **iCloud Drive → Obsidian → PalmWiki** です。ノートのバックアップがあることと、今回の機能がノート本文を変更しないことを踏まえ、本人はこの実Vaultへの配布を承認しました。以後、同じ範囲の配布について同じ確認を繰り返しません。

`PalmWiki_LocalTest`への配置を必須にはしません。Mac上の構文・自動テスト・チェックサム照合は配布前の確認として行い、主要な受入試験は実データのあるiPhone/iPadで行います。Macだけの動作確認をモバイルでの性能確認の代わりにはしません。

この方針は以前のLocalTest限定配布手順より新しい指示です。過去の配布・試験記録はその時点の事実として保持します。新しいVault・サービス・権限への拡大、ノートや分類情報の変更、mainへのマージ、正式Releaseは含みません。

## 0.2.0配布パッケージの変更

プラグイン本体の `main.js`・`manifest.json`・`styles.css` は従来の0.2.0と同一です。変更はインストーラー、開発用の配布試験、運用資料のみです。すでにiCloudのPalmWikiで0.2.0を使っている場合は再配置不要です。

Macの標準候補パスは `$HOME/Library/Mobile Documents/iCloud~md~obsidian/Documents/PalmWiki` とします。スクリプトはこの既存Vaultと既存 `.obsidian` の存在を確認し、見つからない・種類が不正・シンボリックリンクで対象を確定できない場合は止まります。別Vaultへの置換、フォルダ作成による見かけ上の成功、ディスク全体の探索はしません。実機の絶対パスを開発環境で確認したものではありません。

配置対象は `.obsidian/plugins/palmwiki-home-lite/` の3成果物だけです。既存3点を `$HOME/PalmWikiHomeLite-Backups/` 内の個別フォルダへ退避・照合後にコピーし、配置後のSHA-256を検証します。同じ3点が配置済みなら何もしません。設定の `data.json`、プラグインの有効・無効、ショートカット、ノート本文、添付ファイル、既存.baseは変更しません。既存設定の読取りや外部送信もありません。

## 操作

Mac・iPhone・iPadのObsidianを終了した状態で、ZIPを展開して次を実行します。

```bash
bash "$HOME/Downloads/palmwiki-home-lite-0.2.0-icloud/install-macos.command"
```

Mac側のコピー・照合が成功しても、それだけでiCloud経由の全端末への反映は確認済みとはしません。iCloud同期後に各モバイル端末でPalmWikiを開き、コミュニティプラグイン設定のPalmWiki Home Liteが **0.2.0** になっていることを確認します。端末ごとに設定フォルダを変更している場合は、この標準 `.obsidian` への配布だけではその別設定フォルダまで更新しません。

今の設定をそのまま利用し、配布に伴ってOmnisearch・Another Quick Switcher・2hopの設定を変えません。新しいVaultでまだLiteを有効にしていない場合の有効化は利用者のObsidian設定で行います。スクリプトでは切り替えません。

## モバイルで優先して確認すること

| 項目 | 実際に確かめる動作 |
|---|---|
| 起動とHome表示 | 起動後に操作できるまでの待ち、初期24カード、本文・画像の後追い表示中の反応。 |
| スクロールと画像 | 24件ずつ増加し300件で止まること。画像ありでも引っかかりや表示位置の急変がないか。 |
| ノート切替・復帰 | Homeからノートへ移る操作、他アプリに切り替えて戻ったときの再読込・待ち・表示位置。 |
| オフライン | 同期済みのノート・画像を通信なしで開けること。未同期ファイルとの区別。 |

端末・版・画像ON/OFF・操作・観察した結果を簡潔に残します。画像OFFは負荷を切り分ける必要がある場合だけ用い、初めから設定の組合せを大量に試すことは求めません。既存0.1.0に対する本人の軽さの評価を、0.2.0の全項目合格と読み替えません。

## 既知の課題と保留

本人から **iPhoneではボタンが押せない位置になることがある** と報告されています。未修正・未解決として記録し、今回の配布先変更では修正範囲を広げません。モバイル負荷の確認を先に進め、位置・タップ領域の調整は後段で扱います。現時点で全画面のナビゲーション受入完了とはしません。

プロジェクト／エリアの定義・所属モデルは未決定です。専用表示、統合検索欄、プロジェクト内検索、Embedded-Omnisearchの導入は `ROADMAP.md` の後段項目として維持します。

## 復旧と結果の区別

問題があればLiteの画像表示だけOFFにするか、Obsidianを各端末で終了し、退避済みの3成果物を同じ配置先へ戻します。設定とノートは削除しません。iCloud同期後にモバイル側の版と動作を再確認します。

ソース保存、配布ZIPの準備、Mac上へのコピー、iCloud同期、iPhone/iPadでの動作確認を別々の状態として報告します。今回のChatGPT実行環境から実Vaultへのコピーや端末操作は実施していません。
