# PalmWiki Home Lite — 0.2.0 / iCloud配布

本人の2026-09-16の指示により、既定の配布先・主要な受入対象を **iCloud Drive → Obsidian → PalmWiki** に変更しました。最新の配布方針は [DEPLOYMENT.md](DEPLOYMENT.md) にあります。Macのローカルテストだけで受入完了とはせず、実データのあるiPhone/iPadで負荷を確認します。

今回の変更はインストーラー・配布試験・運用資料だけです。`main.js`・`manifest.json`・`styles.css`は従来の0.2.0と同一で、プラグインIDも `palmwiki-home-lite` のままです。すでに本番PalmWikiで0.2.0を使っている場合は再インストール不要です。

## 配布・復旧

Mac・iPhone・iPadのObsidianを終了し、ZIPを展開して次を実行します。Node.jsやnpmの導入は不要です。

```bash
bash "$HOME/Downloads/palmwiki-home-lite-0.2.0-icloud/install-macos.command"
```

標準のObsidian用iCloud領域にある既存 `PalmWiki` を自動確認し、その `.obsidian/plugins/palmwiki-home-lite/` へ3成果物だけを配置します。見つからない・事前検査が失敗した場合は停止し、別Vaultや別サービスへ切り替えません。

既存3点をVault/iCloud外へ退避・照合後にコピーし、配置後にSHA-256を照合します。同じ3点が配置済みなら変更しません。`data.json`、有効・無効、外部コマンド設定、ノート本文、添付、既存.baseは変更しません。Homeの.baseの作り直しも不要です。

Mac上のコピー成功と、iCloud経由のモバイル反映は別です。同期後にiPhone/iPadでPalmWikiを開き、Liteの版番号が **0.2.0** であることを確認してください。端末別の設定フォルダを使っている場合、その別フォルダまでは自動更新しません。

問題があれば画像表示だけOFFにするか、各端末のObsidianを終了して退避した3成果物を戻します。旧ZIPのインストーラーはLocalTest限定なので、本番への復旧にはそのまま使わず、今回の退避先を利用してください。同期後にモバイル側の状態も確認します。

## 0.2.0の機能

- 一覧・並べ替え・フィルターはBasesが担当。初期Homeは全Markdownの更新日時降順です。
- 初期24カード、下端スクロールで24件ずつ追加、最大300件。「続きを表示」も利用できます。タイトルと枠を先に出し、変化していないカードは再利用します。
- 本文は画面付近だけをプラグイン全体で同時2件まで読み込みます。最大280文字の抜粋を最大300件、実行中のメモリに保持し、版が一致すれば再利用します。512 KiB超のノートは本文プレビューを省略します。
- 既存の埋め込みメタデータから、最初の対応ローカルPNG/JPEG/WebP（2 MiB以下）を表示します。先頭100埋め込みまでを確認し、画像のためだけの本文走査はしません。最初の対応画像が大きすぎる場合はテキスト表示です。
- 画像は各Homeビューで同時2件まで、固定枠へ表示し、画面外ではsrcと要素を解放します。同じ画像版のローカルURLでブラウザー側キャッシュを再利用可能にします。独自の画像バイトキャッシュやサムネイル一括生成はありません。
- 外部URL、data/file URL、SVG、GIF、HTML画像、PDFサムネイルは対象外です。エラーとタイムアウトに対応し、画像OFF設定があります。総画素数やPNG/WebPのアニメーション有無は事前検査していません。
- 共通Home／検索／移動ボタンと、Omnisearch／Another Quick Switcherの既存コマンド呼出しを維持します。通常ワークスペースタブが対象で、設定ダイアログやHoverポップアップは対象外です。
- Homeは指定.baseを開き、先頭・初期24件へ戻ります。ピン留めタブは維持して新タブに開きます。初回Home操作時だけ、指定.baseがなければ作成します。

独自全文索引、PageRank、本文永続キャッシュ、起動時の全件本文取得、外部通信はありません。外部検索プラグイン自身の索引は変更しません。2hop改造版から実行時に独立しています。

## 受入・既知の課題

主要な確認はiPhone/iPadでの起動、段階表示、実画像読込中の反応、ノート切替、他アプリからの復帰、同期済みデータでのオフライン利用です。本人から報告された **iPhoneのボタンが押せない位置になる問題** は未修正の既知課題として後段に残します。ビュー再生成後の一覧位置の長期復元も未実装です。

0.2.0実装時には、37件のNode API/DOMダブルテストとChromium＋合成APIの試験結果が保存されています。今回、その実装の3成果物はハッシュ一致で維持し、実Obsidian/iPad受入・独立レビューの完了とはしません。

今回のインストーラー変更は、構文検査と12件の合成ファイルシステム試験が成功しました。対象不一致、退避失敗、破損配布物での停止、配置途中失敗の復旧、同一版の再実行、設定・本文の保持を確認しました。macOS固有のOS/プロセス判定を試験用に置き換えた検証で、実Macや実Vaultへの配置は未実施です。

プロジェクト／エリアの定義は未決定です。専用表示、統合検索、プロジェクト内検索、Embedded-Omnisearchは [ROADMAP.md](ROADMAP.md) の後段項目として維持します。ノートの分類情報を変更しません。

## 開発継続

`AGENTS.md`・`PROJECT_CONTEXT.md`・本ディレクトリの `DEPLOYMENT.md` を参照。追加npm依存なし。Node.js 22以上で:

```sh
npm --prefix lite run build
node lite/test-installer.mjs
```

ビルドは構文検査・テスト・版整合性確認後、`lite/dist/palmwiki-home-lite/` の3成果物と親の `SHA256SUMS` を生成します。2つ目は生成済みdistを使う配布スクリプトの試験です。実Vaultを使いません。生成物・個人データ・試験ログはGitへ入れません。

現在は同じ開発ブランチ・Draft PR #32で管理します。`[skip ci]`を付け、Actions設定・保護ルールは変更しません。mainへのマージ・正式Releaseは別です。従来TypeScript版のルートbuild／Obsidian ESLint、独立レビューなど公開前の未実施検証を成功扱いにしません。

`app.commands`だけは既存の小さな互換境界を維持します。他プラグインの内部索引・設定・DOMには接続しません。
