# PalmWiki Home Lite — 試用版 0.2.0

Basesによる更新順ホームと外部検索・移動ボタンを維持し、初期24件／追加24件／上限300件の連続表示と、最初のローカル画像を追加した試用版です。プラグインIDは `palmwiki-home-lite` のままなので、0.1.0の検索・移動・Home設定を引き継ぎます。既存のPalmWiki Home 0.6.1は変更しません。

## 更新方法

Obsidianを終了してZIPを展開し、macOSのターミナルで次を実行します。Node.jsやnpmの導入は不要です。

```bash
bash "$HOME/Downloads/palmwiki-home-lite-0.2.0/install-macos.command"
```

フォルダ選択画面で既存の `PalmWiki_LocalTest` を指定してください。他のVaultには配置しません。コピーするのは `main.js`・`manifest.json`・`styles.css` の3点のみで、既存Liteの3点をVault外に退避し、コピー前後にSHA-256を照合します。インストーラーはプラグインの有効・無効や `data.json` を変更しません。

Obsidianを開き直すと0.2.0が読み込まれます。Basesは有効、旧PalmWiki Homeは無効のままにしてください。検索・移動ボタンの再設定や.baseの作り直しは不要です。初回導入時に限りHomeクリックで指定.baseがなければ作成します。既存ファイルは上書きしません。

## 今回の動作

### カード一覧

- 初期表示は24件。タイトルとカード枠を先に出し、本文・画像は後から補います。
- 下端に近づくと24件ずつ追加し、最大300件まで。ページ切替は不要です。
- 「続きを表示」ボタンも残し、キーボードや自動追加できない画面で利用できます。起動だけで300件まで自動追加しません。
- 301件目以降は検索かBasesフィルターで絞り込みます。Basesからの結果順を維持し、独自の並べ替えや全Vault本文読み込みは行いません。
- 既存カードを再利用し、追加時に全カードを作り直しません。閲覧途中の更新では可能な範囲で表示位置を保ちます。
- Homeボタンは同じHomeへ戻り、表示数を初期24件に戻して先頭へ移動します。ピン留めタブの扱いは従来どおりです。

### 本文プレビューと画像

- 画面付近だけ読み込みます。本文読込はプラグイン全体で同時最大2件。タイトル描画後に短い待機を置きます。
- 本文は最大280文字の抜粋だけを最大300件、実行中のメモリに保持します。Homeの開き直しではファイル版が一致する抜粋を先に使います。終了時に破棄し、キャッシュファイルを作りません。
- 本文512 KiB超は従来どおりプレビューを省略します。ノートは通常に開けます。
- Obsidianの既存の埋め込みメタデータから、最初のローカルPNG・JPEG・WebP（2 MiB以下）を探します。wiki形式とMarkdown形式の埋め込みに対応し、画像のためだけにノート全文を読みません。確認する埋め込みは先頭100個までです。
- 画像の同時読込は各Homeビューで最大2件。画像は固定枠内へ表示し、後から読み込まれてもカード全体の高さを変えません。
- 画面外へ離れた画像は要素とsrcを解放します。同じ画像版は同じローカルURLを使いブラウザー側キャッシュを再利用可能にし、変更後は版付きURLへ切り替えます。独自の画像バイトキャッシュや全画像のサムネイル生成はしません。
- 遅れて到着したメタデータ、画像の更新・削除を表示に反映します。読み込みエラーやタイムアウトでも一覧を止めません。
- 外部URL、data/file URL、SVG、GIF、HTMLのimg、PDFのサムネイルは対象外。最初の対応画像が大きすぎる場合は別画像にすり替えず、テキスト表示にします。PNG/WebPのアニメーション有無や展開後の総画素数までは事前検査していません。
- 設定の「カードに画像を表示」で画像を無効にでき、比較・復旧が可能です。

画像を小さく表示してもデコードの負荷がゼロになるわけではありません。今回の制御は表示範囲、形式・ファイルサイズ、同時数、画面外解放であり、実画像のメモリ使用を一定値以下と保証するものではありません。

## 維持したもの・今回しないこと

Home／検索／移動の共通ボタン、Omnisearch／Another Quick Switcherの既存コマンド起動、Basesのフィルター・保存済みビュー、2hop改造版は維持します。ボタンは通常のワークスペースタブが対象で、設定ダイアログやHoverポップアップは対象外です。

外部検索プラグインの索引やキャッシュはそのプラグイン自身が管理します。Liteは独自全文索引、PageRank、本文永続キャッシュ、起動時の全件本文取得、外部通信を追加しません。

プロジェクト／エリアの定義、所属情報の書込み、専用PARA表示、Embedded-Omnisearch導入、統合検索欄、プロジェクト内検索は今回実装しません。将来計画は `ROADMAP.md` に分けました。ノート本文・frontmatter・添付画像・既存.baseは変更しません。

## 検証と未確認

0.1.0については本人から「かなり軽い」「検索・移動も設定できた」との試用報告がありました。0.2.0の実端末受入と混同しません。

0.2.0はNode.js 22.16.0で構文検査・37件のAPI/DOMダブルによるテスト・ビルド・版整合性検査が成功しました。1万件の合成データから初期24件・最大300件、画面外読込の抑制、抜粋キャッシュの上限と版判定、画像の遅延／破損／更新／解放、共通ボタンと外部コマンド設定の維持を確認しています。

別途、Chromiumの実DOMに合成Obsidian APIを接続した試験で、24→300件のスクロール追加、画面外画像の解放、更新時の位置保持、390px幅での横はみ出しなし、破棄時の画像清掃を確認しました。実Obsidianではなく、OSによるメモリ回収やiPad復帰の証明ではありません。

ルートの従来TypeScript版に対する `npm run build` / Obsidian ESLint、独立レビュー、macOSでのインストーラー実行、実Obsidian／iPadの試験はこの更新では未実施です。開発環境には従来版の依存関係がなく、ネットワーク経由の取得もできませんでした。CIは実行していません。

### 実機で確認する項目

- 起動後は少数のカードが先に出て、本文・画像が遅れて補われること。
- 下端で表示が増えて300件で止まり、Homeで先頭へ戻ること。
- 画像あり／なしが混在した一覧で、ノートへの移動や上部ボタンが滑らかなこと。
- 日本語画像名、同名画像の別フォルダ、画像の変更／削除、破損画像、機内モード。
- 2hop表示、ピン留め、戻る・進む、分割、iPad横縦とアプリ復帰。

ビュー再生成後の一覧の表示件数・スクロール位置の長期復元は未実装です。通常のノート表示の復元はObsidian側に委ねています。現在の300件上限内でも、実データ・端末・他プラグインでの性能差は別途確認します。

## 戻し方

まずLiteの設定で画像表示だけをOFFにできます。0.1.0全体へ戻す場合はObsidianを終了し、前回配布ZIPの同じインストーラーを実行すれば、3ファイルを戻せます。検索・移動設定は維持されます。今回のインストーラーが出力した退避先の3ファイルを戻す方法でも構いません。

従来のPalmWiki Homeへ戻す場合はLiteを無効にし、旧版を有効にします。旧版の設定・索引は触っていません。.baseは既存か新規作成かを確認せずに削除しないでください。

## 開発継続

`AGENTS.md`・`PROJECT_CONTEXT.md`を参照。変更は `lite/` 配下、既存の `codex/lightweight-bases-home-mvp` ブランチとDraft PR #32です。追加npm依存なし。Node.js 22以上で:

```sh
npm --prefix lite run build
```

構文検査、テスト、版整合性確認後に `lite/dist/palmwiki-home-lite/` の3成果物と親の `SHA256SUMS` を生成します。生成物・個人データ・試験ログはGitへ入れません。公開前には従来の必須チェックと独立レビューを別途完了してください。

`app.commands`だけは公開型APIにない既存の互換境界を維持しています。他プラグインの内部索引・設定・DOMへは接続しません。commitは `[skip ci]` を付け、Actions設定・保護ルールは変更しません。mainへのマージ・タグ・正式Release・日常Vaultへの配置は未実施です。
