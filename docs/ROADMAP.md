# ROADMAP

1.0（2026-09-27）で、Lite 試作を PalmWiki Home として引き継ぎました。方針と次の候補です。

## 変えない方針

- 初期表示とノート切替の軽さを最優先にします。独自の全文検索索引・PageRank・本文の永続キャッシュは戻しません。
- 初期24件、下端で24件ずつ追加、最大300件。本文の抜粋と最初のローカル画像は、画面の近くだけ後から補います。
- 一覧・並べ替え・絞り込みは Bases に任せます。関連ノートは 2hop-links-plus（改造版）に任せ、同じ機能を作りません。
- 確認の中心は、iPhone・iPad と実データです。Mac や合成テストだけでは完成としません。

## 次にやること

1. **iPhone でボタンが押せない位置になる問題**（本人報告）。画面幅・安全領域・キーボードとの関係を実機で確かめて直す。
2. **プロジェクト／エリア別の表示**（必ず付ける構想）。PARA-PKM で、所属は frontmatter の tags（`Projects`・`Areas`）と status で表すと決まったので、それを使う Bases の保存済みビューを用意する（本人確認のうえ）。
3. **検索の一本化**（後段）。フォーカス直後は最近のノート、入力中はタイトル・別名の候補、確定で Omnisearch の本文検索、という1つの検索欄を目指す。Omnisearch の公開 API（`omnisearch.search()`）は結果を返せる。Another Quick Switcher の API は選択画面が中心なので、使っている版で確かめてから決める。
4. プロジェクト内に絞った検索は低優先。2hop 側の機能で代わりになるかも検討する。

## 観察を続けること

- 他のアプリから戻ったときの待ち（プロセスが残っている場合と、OS に再起動された場合を分けて記録する）。
- 画像を表示したときに引っかかるか（画像表示をオフにした場合と比べる）。
- ビューを作り直したあとに、一覧の位置が戻らないこと（未実装）。
